# Support

## Getting Help

Use the following channels:

- GitHub Issues: bug reports and feature requests
- GitHub Discussions: usage questions and design conversations

When opening a request, include:

- Kubernetes version
- Operator version/tag
- CR manifest (sanitized)
- Relevant controller and runner logs
- Reproduction steps

## Before Opening an Issue

- Read `README.md`
- Check `docs/jobs-and-kubernetes.md`
- Verify sample manifests under `config/samples/`

## Scope

This project is maintained on a best-effort basis.
